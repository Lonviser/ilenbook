# ilenbook 0.2.0 — проверка

22 октября 2026 года. Android Emulator / Android 15 API 35 x86_64, профиль Pixel 6. Реальная сенсорная электронная книга пользователя не подключалась.

## Флибуста: реальная проверка в Android

Успешно выполнены запрос каталога, поиск названия «Каштанка», поиск автора «Чехов», скачивание и чтение EPUB Антона Павловича Чехова. Это запросы из нативной части Android, без тестового прокси.

- Корень: Flibusta catalog.
- Поиск по названию: 9 результатов.
- Поиск автора: 18 результатов, включая «Чехов Антон Павлович».
- Скачанная книга: «Каштанка», автор «Антон Павлович Чехов», EPUB, 37 350 символов распознанного русского текста.
- Исходный файл: 109 371 байт. Он сохраняется отдельно от текста читалки.
- Поиск в UI также проверен: введённый запрос «Каштанка» остаётся на экране, выдача приходит сразу по выбранному виду поиска, без промежуточного раздела сервера.

HTTPS сервера периодически не отвечал; резервный запрос по HTTP к тому же домену позволил выполнить операции. HTTP не шифрует трафик. Гарантировать доступность внешнего сервера в любой сети приложение не может.

## Чтение и заметки

Автоматический сценарий `tools/v2-reader-checks.cjs` прошёл в браузерном предпросмотре и в настоящем Android WebView:

1. Нажатие справа перемещает вперёд, слева возвращает назад.
2. Выбранный Lora применяется и загружается из APK.
3. Выбранная анимация сдвига запускается.
4. Цитата из выделения и пользовательская заметка сохраняются.
5. Заметка редактируется и остаётся после перезагрузки страницы приложения.
6. Шаблоны поиска с закодированными скобками и кириллицей корректно формируют URL; старый мобильный адрес Gutenberg нормализуется.

Три TTF дополнительно проверены в Android через загрузку FontFace: Lora — 212 196 байт, Literata — 955 132, Source Sans 3 — 646 340; все декодируются без ошибок. Обнаружена и исправлена проблема обратных слэшей во вложенных assets, создаваемых Windows AAPT2.

Настоящее долгое нажатие Android на слове «чудная» выделило слово, показало действия «Заметка» и «Перевести» и не изменило позицию страницы. Нажатие «Заметка» открыло редактор с этой цитатой. Синтетический CDP touch не воспроизвёл платформенное выделение; для этой проверки использовался реальный Android input swipe с удержанием.

## Перевод

Через UI Android выполнен перевод `book → книга` сервисом MyMemory. Повторное нажатие вернуло перевод из локального кэша. Языки выбираются пользователем; интернет нужен для новых слов. Полного офлайн-словаря нет.

## Экспорт

Скачанный с Флибусты EPUB сохранён через Android ACTION_CREATE_DOCUMENT в Downloads/Каштанка.epub. Сравнены исходный приватный файл приложения и экспортированный файл: побайтно идентичны, по 109 371 байту.

SHA-256 экспортированной книги: `772f796addfd5c51f6b139cc81dd0aa930d6ecd4b7e093e10ab32a8ba0f5b2a6`.

Android-меню передачи показывает имя «Каштанка.epub»; ContentProvider отдаёт файл с временными правами чтения. Добавлен отдельный ACTION_VIEW для открытия в приложении-читалке. Сторонняя читалка на этом эмуляторе не установлена, поэтому открытие в конкретном стороннем приложении не проверялось. Стандартный EPUB сохранён без изменения содержимого.

## Регрессии и сборка

- 13 JVM-проверок импортера прошли повторно.
- В браузере прошли прежние 8 сценариев библиотеки/читалки: поиск, избранное, закладка, тема, позиция, поиск в тексте, оглавление и полка избранного.
- Обновление устанавливалось поверх прежней версии без очистки данных; скачанная книга, настройки и закладки сохранились.
- Финальный APK собирается без `DebugWebView`, с versionCode=2 и versionName=0.2.0; подпись тем же локальным ключом разработки.
- Финальный APK повторно установлен и запущен: имя ilenbook, отладка отключена; библиотека со скачанным EPUB сохранилась. Скриншот `ilenbook-library.png` сделан с итоговой сборки. Во время тестов один раз завершился служебный процесс Android UiAutomation с Bad file descriptor; процесс приложения при этом не завершался.

Для дальнейших испытаний нужен конкретный E Ink-девайс: скорость обновления его экрана, версия Android/WebView, работа собственного режима обновления и аппаратных кнопок зависят от производителя.
