# Проверки ilenbook 0.7.4

23 октября 2026, Europe/Minsk. Windows, Chrome, Android 15 x86_64 эмулятор. Физическое устройство не использовалось.

## Автоматические проверки

`tools/test-parser.ps1`: 128 Java-проверок, включая 32 новые проверки обновлений: стабильная версия, числовое сравнение, источник и имя APK, обязательная SHA-256, размер, HTTPS/перенаправления, чужой пакет, несовпадение версии, другой сертификат, CI-ключ, несколько подписей, откат, SDK и интервалы автопроверки. Прежние 96 проверок парсинга, копии, протоколов и каталогов сохранены. Дополнительно проверяется синтаксис JavaScript; 15 проверок модели оставшегося времени входят в CI.

`tools/v11-updates-ui.cjs`: шесть групп с тестовыми ответами — независимые настройки автопроверки/скачивания, ручная проверка, прогресс и отмена, установка готового файла, пассивное отображение релизных заметок, размеры 320/360/412/600 и уведомление без модального окна.

## Настоящий APK и системная установка

Для проверки собрана отладочная клиентская сборка с новым модулем обновлений, но тестовыми полями манифеста 0.7.2/versionCode 9. Это специальная локальная тестовая сборка, не опубликованный APK 0.7.2.

Она получила настоящий стабильный релиз 0.7.3 из публичного GitHub API, скачала 40 205 279 байт, проверила SHA-256 `a566d9a1e18ac5770e5f0ac6dcda67a1fae63979060b8e8f371875ef6f1fb43a`, пакет и подпись. Было открыто системное окно разрешения установки из ilenbook; после включения разрешения и возврата открылось подтверждение обновления. Подтверждение в Android установило настоящий опубликованный APK 0.7.3/versionCode 10, без удаления приложения.

Затем установлен итоговый подписанный 0.7.4/versionCode 11. Все семь тестовых книг сохранились. Проверены ручной запрос состояния, отсутствие предложения отката к более старому релизу, переключение автопроверки и очистка установленного готового APK. Настройки автоматического скачивания проверены в интерфейсе; эмулятор использовал нетарифицируемую сеть Wi-Fi. Постоянная работа при закрытом приложении не заявляется.

Итоговый APK собирается без `-DebugWebView`: `debuggable=false`, прежний пакет и сертификат, 29 файлов assets совпадают с исходниками по SHA-256, восемь библиотек Tor/Lyrebird для четырёх ABI. APK, архив исходников и SHA-256 публикуются вместе.

Сетевые алгоритмы каталогов и чтение в этом выпуске не менялись. Старые проверки — в отчётах [0.7.1](VALIDATION_0.7.1.md), [0.7.2](VALIDATION_0.7.2.md), [0.7.3](VALIDATION_0.7.3.md).
