# ilenbook 0.7.1

- Исправлена обработка адресов Флибусты: подключение охватывает основной OPDS-сервер, обложки, статические файлы и перенаправления. Рабочий HTTP-маршрут повторно используется при недоступном HTTPS.
- Увеличено ожидание готового файла книги: сервер может долго формировать EPUB/FB2. Оригиналы по-прежнему сохраняются для других читалок.
- Добавлено встроенное резервное подключение к Флибусте через Tor и мост Snowflake. В разделе «Поиск → Подключение Флибусты» можно выбрать режим и проверить живой каталог. Отдельный Orbot не требуется.
- Ширина кнопок панели чтения адаптируется к экрану. «Оглавление» больше не переносит последнюю букву на новую строку.
- Внизу чтения отдельно показаны проценты всей книги и текущей главы, а также номера главы и страницы. Прогресс книги учитывает объём текста глав, а не только их количество.
- Рядом с прогрессом показано примерное время до конца книги и главы. Начальная оценка — 1200 знаков в минуту; после нескольких страниц активного чтения используется личный темп. Он хранится локально вместе со статистикой. Быстрые перелистывания, возвраты и время в меню не обучают расчёт; при отключённой статистике остаётся начальная оценка.
- Отложенная перестройка страницы после изменения размеров экрана сохраняет последнюю позицию, включая перелистывание до завершения перестройки.

Устанавливайте `ilenbook-0.7.1.apk` поверх предыдущей версии без удаления приложения. Android 8.0+. Пакет и сертификат подписи сохранены.

Первое резервное соединение может занять до трёх минут; его доступность зависит от сети. Прямой HTTP не шифрует трафик. Tor используется только для запросов Флибусты и автоматически выключается после простоя. Сохранённые книги читаются без подключения.
