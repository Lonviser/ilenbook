# Проверка версии 0.1.0

Дата: 22 октября 2026 года. Среда: Windows, Android SDK Platform 35 / Build Tools 35.0.0, JBR 25 с компиляцией Java `--release 8`. Android Emulator, образ Android 15 / API 35 / x86_64, профиль Pixel 6. Финальный APK универсальный по процессору: собственных нативных библиотек в нём нет.

## Сборка и установка

- APK собран `build-apk.ps1`, выровнен zipalign и подписан локальным ключом разработки.
- `apksigner verify --verbose`: схемы подписи v2 и v3 проверены.
- Установка через ADB и запуск `by.list.reader/.MainActivity` прошли.
- Для интеграционных UI-проверок собирался вариант с отладкой WebView. Финальный файл собран заново без `-DebugWebView`; сетевой и файловый код в вариантах одинаков. Финальная сборка повторно установлена и запущена.
- Физический Android-телефон не подключался. Совместимость всех устройств Android 8+ не проверена: это заявленный минимум SDK, а не результат испытаний на каждой версии.
- В финальной сборке после чистого запуска открыта встроенная книга через системное нажатие. Скриншоты библиотеки и читалки сохранены в `docs/library-android.png` и `docs/reader-android.png`. Проверены отступы от системных панелей Android 15; отладка отключена в скомпилированном манифесте.

## Проверки импортера — 13 пройдены

JVM-проверки из `tools/ParserChecks.java`:

1. TXT UTF-8 с кириллицей.
2. TXT Windows-1251.
3. TXT UTF-16.
4. FB2: название, автор и порядок разделов.
5. FB2 внутри ZIP и вложенной папки.
6. EPUB: container.xml, OPF, метаданные и относительные пути.
7. Порядок глав EPUB по spine, а не по порядку файлов в ZIP.
8. Исключение script из текста EPUB.
9. Отклонение HTML-страницы вместо TXT.
10. Отклонение ZIP с неподдерживаемым содержимым.
11. Отклонение пустой книги.
12. Отклонение XML с объявлением внешней сущности.
13. Отклонение того же объявления в UTF-16.

В тесте на Android обнаружена и исправлена несовместимость защитных SAX-feature с системным XML-провайдером. XML с DTD и объявлениями сущностей отклоняется до DOM-парсинга; внешние ресурсы также блокируются EntityResolver.

## Интеграция Android — 5 сценариев пройдены

`tools/fixture-server.cjs` предоставляет контролируемый локальный OPDS. Внутри настоящего Android-приложения через JavaScript bridge выполнены:

- HTTP-запрос, разбор OPDS, два элемента, шаблон поиска и разрешение относительных URL.
- Скачивание EPUB, нативный парсинг двух глав, сохранение, повторное чтение из файлового хранилища и удаление.
- Такой же сценарий для FB2.
- Скачивание и удаление TXT.
- Отклонение HTML-ответа вместо книги.

Тестовый сервер нужен только для проверки разработчиком; приложение пользователя не зависит от него. Адрес тестового сервера не добавляется в список источников поставляемого APK.

## Интерфейс Android — 8 сценариев пройдены

Playwright CLI подключался к отладочному WebView через ADB/CDP. Файл сценария — `tools/ui-checks.cjs`.

1. Поиск «Чехов» возвращает две встроенные книги автора.
2. Добавление книги в избранное.
3. Переход на следующий экран и добавление закладки.
4. Включение сепии.
5. Выход из читалки, повторное открытие и восстановление позиции.
6. Поиск слова по тексту и переход к найденному абзацу с выделением.
7. Оглавление и переход в другую главу.
8. Наличие выбранной книги на полке избранного.

Тот же сценарий прошёл в браузерном предпросмотре шириной 390 px. Отдельно через настоящий Android DocumentsUI выбран `/sdcard/Download/list-sample.txt`: книга появилась в библиотеке как TXT с источником «С устройства». Это проверяет системный выбор файла и чтение ContentResolver, а не только загрузку через HTTP.

Во время UI-проверки исправлено повторное открытие настроек из-за слишком широкого селектора обработчиков темы.

## Внешние каталоги

В начале работы прямой запрос с компьютера к `https://flibusta.is/opds` вернул реальную XML-ленту «Flibusta catalog», разделы и шаблон `/opds/search?searchTerm={searchTerms}`. Позже сервер перестал отвечать в доступное время как с компьютера, так и из Android-эмулятора. Приложение показало сообщение о тайм-ауте. Успешная загрузка конкретной книги с внешнего сервера Флибусты в этой сессии не подтверждена.

Преднастроенный Project Gutenberg также требует отдельной проверки из сети пользователя. Наличие источника в списке не означает гарантию доступности сервера.

## Следующая проверка на телефоне

Установить APK, проверить внешний каталог в сети телефона, скачать доступную книгу, открыть её в авиарежиме, закрыть приложение и проверить восстановление позиции. Перед широкой публикацией нужен корпус реальных EPUB/FB2, тесты нехватки места, поворота экрана, системного увеличения шрифта и обновления приложения.
