# Лист — Android-библиотека и читалка

Устанавливаемый APK: [dist/List-0.1.0.apk](dist/List-0.1.0.apk). Android 8.0 и новее. Интерфейс на русском языке. Первая рабочая версия, 0.1.0.

## Установка

1. Скопируйте `dist/List-0.1.0.apk` на телефон.
2. Откройте APK через приложение «Файлы» и разрешите этому приложению установку из данного источника, если Android попросит.
3. Установите «Лист». Для чтения встроенных и импортированных книг интернет не нужен.
4. Для онлайн-библиотеки откройте «Каталог → Флибуста». Перейдите в раздел или введите автора/название в поиск. Откройте книгу, выберите формат и нажмите «Скачать в библиотеку».
5. Для своего файла нажмите плюс на главной странице. Поддерживаются EPUB, FB2, FB2.ZIP и TXT.

APK подписан локальным ключом разработки. Обновления поверх установленной версии должны быть подписаны тем же ключом. Для выпуска в магазин понадобится отдельный защищённый ключ и подготовка релизной сборки. Ключ этой сборки лежит локально в `.tools/list-dev.keystore`; не входит в архив исходников. Нельзя считать его производственным секретом: это ключ тестовой версии.

## Что работает

- Библиотека с обложками, сеткой и списком, поиском, сортировкой, избранным и статусами «Читаю», «Отложено», «Прочитано».
- Импорт через системный выбор файлов Android. Книга копируется в приватное хранилище приложения.
- OPDS 1.x / Atom: разделы, следующая страница, поиск по шаблону каталога или OpenSearch, скачивание поддерживаемых файлов. Источники можно добавлять, редактировать и удалять.
- Источник Флибусты преднастроен: `https://flibusta.is/opds`. Доступность зависит от сети и сервера; копии базы в APK нет. Автоматически загружается список выбранного раздела, файлы книг скачиваются по нажатию пользователя.
- Чтение с вертикальной прокруткой, кнопками и горизонтальным жестом для перехода на экран. Оглавление, поиск по тексту и закладки.
- Светлая тема, сепия, тёмная тема, шрифт с засечками и без, размер, интервал, поля и выравнивание.
- Сохранение позиции, настроек, статусов и закладок на устройстве. Экран не гаснет во время чтения.
- Пять классических произведений с Викитеки и встроенное руководство. Индивидуальные обложки выполнены средствами CSS, без современных издательских изображений.

## Ограничения первой версии

- Это локальная читалка с OPDS, без облачной учётной записи, синхронизации между устройствами и сервера рекомендаций.
- EPUB/FB2 преобразуются в текстовые главы. Основной текст и обложка сохраняются; сложная вёрстка, таблицы, иллюстрации внутри текста, интерактивность и навигация по сноскам не воспроизводятся. Режима разворота и анимации изгиба листа пока нет.
- PDF, аудиокниги, DRM, OPDS 2 JSON, авторизация в каталогах, Tor/I2P и фоновая очередь загрузок не реализованы.
- Размер входного файла до 40 МБ, суммарный распакованный объём архива до 80 МБ. Крупные изображения обложек пропускаются.
- Процент позиции приблизительный: рассчитывается по номеру раздела и прокрутке внутри него; номер страницы относится к текущему разделу и зависит от размера экрана и шрифта.
- Книги и прогресс хранятся локально. Удаление приложения удаляет эти данные; экспорт резервной копии пока не реализован.
- Доступ к каталогу не гарантирует доступность каждого файла: сервер может возвращать ошибку, перенаправление или неподдерживаемый формат. Приложение показывает фактическую ошибку. Используйте произведения, которые вы вправе скачивать.

## Устройство проекта

`app/src/main/java/by/list/reader/MainActivity.java` — Android Activity, WebView, системный импорт, файловое хранилище, HTTP и OPDS.

`app/src/main/java/by/list/reader/BookParser.java` — импорт EPUB/FB2/ZIP/TXT, чтение метаданных и глав, ограничение распаковки и отключение внешних XML-сущностей.

`app/src/main/assets/` — автономный интерфейс HTML/CSS/JavaScript и стартовые книги. Всё включено в APK, отдельного веб-сайта или сервера интерфейса нет. Доступ к сети для каталога выполняет Android-код. Книжная HTML-разметка не исполняется: интерфейс получает текст и экранирует его.

`docs/DEVELOPMENT_PLAN.md` — этапы дальнейшей разработки и критерии готовности. `docs/VALIDATION.md` — фактические проверки этой сборки.

## Сборка

Требуется JDK с `java`, `javac`, `keytool`, Android SDK Platform 35 и Build Tools 35.0.0.

На Windows:

```powershell
.\build-apk.ps1 -SdkPath 'C:\Android\Sdk' -JdkPath 'C:\Java\jdk-17'
```

Скрипт собирает ресурсы через AAPT2, компилирует Java, преобразует классы в DEX через D8, выравнивает и подписывает APK. Текущий APK собран этим скриптом. Также приложены Gradle-файлы для открытия проекта в Android Studio; Gradle-сборка в этом окружении не запускалась.

Для диагностики WebView в эмуляторе используйте `-DebugWebView`. Финальный APK собирается без этого параметра: `android:debuggable=false`.

Проверки импортера:

```powershell
.\tools\test-parser.ps1 -JdkPath 'C:\Java\jdk-17'
```

Для предпросмотра интерфейса:

```powershell
node tools/preview.cjs
```

Откройте `http://127.0.0.1:4189`. Предпросмотр показывает те же встроенные книги; системный импорт, OPDS и скачивание выполняются только в Android-приложении.

## Источники

Оригинальные тексты: [Викитека](https://ru.wikisource.org/). Адрес каждой исходной страницы сохранён в карточке соответствующей книги и в `seed-books.json`. Скрипт `tools/prepare-books.cjs` воспроизводит получение и подготовку текстов; для него нужен интернет. Приложение не скачивает эти тексты при первом запуске — они уже внутри APK.

Протокол каталога: [OPDS Catalog 1.2](https://specs.opds.io/opds-1.2). Инструменты сборки: [Android SDK](https://developer.android.com/tools).
