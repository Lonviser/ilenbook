# ilenbook 0.3.0 — общий поиск, обложки и скорость

22 октября 2026 года. Проверки выполнены внутри приложения на Android Emulator, Android 15 API 35 x86_64. Отдельная сенсорная электронная книга не подключалась.

## Общий поиск

Реальный запрос «Каштанка» отправлен в пять подключённых каталогов. Ответили все пять: Флибуста — 9 записей, общий Gutenberg — 1, его русскоязычный раздел — 1, Wolne Lektury — 0 и Ebooks libres et gratuits — 0. После объединения повторных публикаций показаны 8 результатов. У пяти были ссылки на обложки; видимые изображения загрузились в Android. Это результаты конкретного запроса, а не размеры библиотек.

Контролируемый сценарий с быстрым, дублирующим, медленным и недоступным источниками подтвердил:

- первые две книги доступны до завершения медленного запроса;
- повторные публикации объединяются с сохранением трёх названий источников;
- HTTP 503 одного источника не скрывает результаты других;
- работают фильтр источника и открытие карточки с правильным источником;
- обложка загружается и отображается;
- отменённый старый запрос не подменяет новый, остановленный поиск не добавляет поздние результаты.

Сценарии: `tools/global-v3-check.cjs`, `tools/global-cancel-v3-check.cjs`, `tools/real-global-v3-check.cjs`. Локальные тестовые источники подменялись только в памяти теста, после чего исходный список восстанавливался. В APK они не добавлены.

## Обложки

Поддержаны ссылки OPDS image/thumbnail и x-stanza-cover-image. Изображения, переданные прямо в XML как data URI, не ломают выдачу; поддерживаемые растровые data URI отображаются, неподдерживаемые пропускаются. Этот случай проверен на настоящем ответе Gutenberg.

На тестовой FB2 без встроенного изображения проверена цепочка: ссылка на обложку из каталога → загрузка → преобразование в JPEG → сохранение в метаданных книги → повторное чтение из файлового хранилища. Тестовая книга после проверки удалена.

После остановки тестового сервера повторный запрос обложки вернул сохранённое изображение из кэша, без сети. Автоматический подбор по названию и автору также добавил настоящие обложки нескольким ранее встроенным книгам на полке. Неоднозначные совпадения и отсутствие изображения оставляют оформленную текстовую обложку.

Сценарий: `tools/cover-v3-check.cjs`. Изображения ограничиваются по объёму загрузки и размеру декодирования, уменьшаются до 640 px по большей стороне. Дисковый кэш изображений ограничен примерно 300 файлами; обложка, сохранённая в метаданных книги, от очистки этого кэша не зависит.

## Скорость

На реальном запросе «Каштанка» из Android измерены:

| Измерение | Время |
|---|---:|
| Первые результаты | 801 мс |
| Все пять каталогов завершили ответ | 6531 мс |
| Повторный общий поиск с кэшем всех пяти каталогов | 27 мс |

Сценарий: `tools/search-speed-v3-check.cjs`. Замеры относятся к этой сети, состоянию серверов и эмулятору. Они не гарантируют такую же скорость на другом устройстве или для любого запроса.

Ускорения: шесть фоновых исполнителей для запросов, отдельные исполнители для изображений, результаты каталогов на диске с TTL 10 минут, запоминание рабочего HTTP-подключения Флибусты на 30 минут, повторное использование OpenSearch-шаблонов. Группы запросов получают отмену при новом поиске; активные HTTP-соединения отключаются отдельным служебным исполнителем, не блокируя интерфейс.

Итоговая сборка повторно установлена и запущена: манифест подтверждает `debuggable=false`, интерфейс показывает ilenbook и сохранённые семь книг. Подписи v2/v3 проверены. Все 13 проверок импортера также прошли повторно.
