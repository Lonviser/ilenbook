# ilenbook 0.5.0 — экспериментальное подключение Яндекс Книг

22 октября 2026. Android 8.0+, пакет и подпись сохранены. Устанавливать поверх 0.4.0 без удаления приложения.

Добавлено подключение аккаунта через сайт Яндекса. Реализованы запросы библиотеки, статусов, прогресса, названий полок, цитат/комментариев и доступной статистики. Книги показываются на общей полке; прежние ручные ссылки сохраняются и не дублируются на полке при совпадении URL.

Есть ручное обновление, обновление при открытии по выбору, частичные ошибки с сохранением кэша, отмена и отключение аккаунта. Цитаты можно искать и экспортировать в Markdown; показатели Яндекса отделены от локальной статистики. Диагностика подключения экспортируется без содержимого аккаунта.

Вход изолирован от Native-моста читалки. Токен зашифрован Android Keystore, не доступен JavaScript и не входит в ZIP-копии. Аккаунт после переноса нужно подключить заново. Локальные книги, заметки, статистика и настройки продолжают работать.

Подключение неофициальное. Тесты с подготовленными ответами и настоящая страница входа проверены; полный вход и получение личных данных требуют проверки пользователем на устройстве. Подписной текст встроенная читалка не получает. Передача точного места и заметок обратно не реализована. Названия полок открываются в Яндексе, состав полок внутри ilenbook пока не загружается.

Инструкция и ограничения: `YANDEX_CONNECTION.md`. Проверки: `VALIDATION_0.5.md`.
