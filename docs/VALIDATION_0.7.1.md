# Проверки ilenbook 0.7.1

Дата клиента: 23 октября 2026, Europe/Minsk. Среда: Windows, Android 15 x86_64 эмулятор, Chrome/WebView и Playwright. Физическое устройство и настоящий аккаунт Яндекса не использовались.

## Автоматические проверки

`tools/test-parser.ps1`: **96 проверок пройдены** — прежние 80 проверок парсинга, резервной копии, протокола Яндекса, параллельного сетевого запроса и публичных каталогов; ещё 16 проверок адресов Флибусты и перенаправлений через Tor.

`node tools/reading-time-checks.cjs`: **15 проверок расчёта оставшегося времени** — объём разных глав, округление, конец книги, личный темп, некорректные сохранённые значения, предел истории и отключённая статистика. Этот набор также запускается в GitHub Actions.

Проверен синтаксис всех JavaScript-файлов. APK собран без `-DebugWebView`; `android:debuggable=false`, пакет `by.list.reader`, versionCode 8, versionName 0.7.1. Сертификат совпадает с предыдущим релизом. Все 28 файлов assets внутри APK сравниваются с рабочими исходниками по SHA-256. Tor/Lyrebird включены для ARM64, ARMv7, x86 и x86_64; бинарные архивы проверяются по закреплённым SHA-256.

## Флибуста: реальные сетевые запросы в Android

`tools/v8-flibusta-direct.cjs` обращается к OPDS с новым параметром проверки, поэтому результаты поиска не берутся из дискового кэша. Он ищет Чехова, загружает FB2.ZIP, читает русский текст и проверяет сохранённое имя исходного файла. Созданная только для проверки книга удаляется, прежние книги сохраняются.

Один из успешных замеров при уже выбранном рабочем HTTP-маршруте:

| Действие | Результат |
|---|---|
| Корень каталога без кэша | 859 мс, 5 разделов |
| «Каштанка», книги без кэша | 393 мс, 9 записей |
| Повтор того же запроса | 6 мс, результат из кэша |
| «Чехов», авторы без кэша | 306 мс, 18 записей |
| Обложка | JPEG, 28 507 символов data URL; в этом замере из кэша изображения |
| Скачивание и разбор | 13 439 мс; «Каштанка», Антон Павлович Чехов, 37 542 символа |
| Исходник | `Каштанка.fb2.zip`, пригоден для экспорта в другую читалку |

`tools/v8-flibusta-ui-timing.cjs` проверяет настоящий общий интерфейс с выбранной Флибустой. «Толстый и тонкий»: до запроса кэш книг и авторов отсутствовал; первые книги появились за **1 146 мс**, поиск завершился за 1 159 мс. Повтор: первые книги за **41 мс**, завершение за 43 мс. Найдены две книги, ошибок источника нет.

На окончательном APK с оставшимся временем чтения прямой сценарий повторён: корень 1 256 мс, поиск книг без кэша 384 мс, повтор из кэша 17 мс, авторы 356 мс, скачивание и разбор 12 795 мс. Русский текст и исходный `Каштанка.fb2.zip` подтверждены.

## Встроенный резервный путь

`tools/v8-flibusta-reserve.cjs` принудительно выбирает Snowflake, проверяет живой корень, новый поисковый URL, обложку с новым параметром, скачивание FB2.ZIP и наличие русского текста. Прямой маршрут в этой проверке не используется.

Успешный Android-прогон: подготовка соединения вместе с первым OPDS-запросом **103 649 мс**, поиск без кэша **9 331 мс**, обложка **1 237 мс**, загрузка и чтение книги **5 061 мс**. Статус Tor — 100%, полный сценарий пройден. Метаданные сети Tor к этому моменту частично сохранены после предыдущих попыток. Отдельно проверен ответ официального onion-адреса через Tor-клиент.

Доступность моста нестабильна: первые попытки с меньшим лимитом завершались на 50–68% подготовки или ожиданием ответа. Итоговый лимит подготовки Snowflake — 150 секунд; автоматический режим перед ним также кратко пробует обычный Tor. Это резерв на случай недоступности прямого пути, не обещание ускорения заблокированной сети. Запрос можно отменить; библиотечные источники отвечают независимо. Активная загрузка удерживает соединение, после трёх минут простоя процесс выключается. Таймауты загрузки исходных файлов отделены от коротких сетевых проб каталога.

## Чтение и интерфейс

- `v8-reader-progress.cjs`: ширины 320/360/412/600 в браузере и Android WebView; «Оглавление» занимает одну строку, панель и проценты не выходят за экран. Отдельно сверяется взвешенный по длине текста процент всей книги и процент главы.
- `v8-reading-time-ui.cjs`: 7 групп — время книги/главы на 320/360/412/600 px, сохранение личного темпа, исключение быстрых перелистываний и меню, отключение статистики, длинные книги и прокрутка. Время в проверках обучения задаётся тестовыми отсчётами, без ожидания реального чтения. Отдельно воспроизведён и устранён возврат на прежнюю страницу после отложенного resize.
- `v4-statistics-checks.cjs`: 6 групп — активное время, пауза, бездействие, завершение, разделение по дням и экспорт.
- `v8-flibusta-settings.cjs`: вход из поиска, сохранение режима в Android, настоящий тест каталога без кэша и отображение ответа.
- `v6-reader-customization-checks.cjs`: 10 групп — профили, отдельное оформление, позиция после шрифта, меню и зоны. При проверках обнаружена ранняя готовность страницы до загрузки первого веб-шрифта; глава теперь ждёт выбранный шрифт, повторный полный прогон пройден.
- `v6-search-progress-checks.cjs`: 6 групп — выдача книг до авторов, кэш/обновление, сетевой отказ и устаревшие ответы.
- `v7-discovery-checks.cjs`: 11 групп — виды библиотеки, источники, фильтры, история, независимые повторы и размеры экранов.

Скорость — замеры в текущей сети, не гарантия для других устройств и провайдеров. Прямой HTTP не шифрует запросы; резервный onion-маршрут работает внутри Tor. Обход недоступности не гарантирован, в отдельных сетях может понадобиться VPN. Физическая читалка, ARM-устройства и реальный аккаунт Яндекса требуют проверки на устройстве владельца.
