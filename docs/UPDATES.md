# Обновления ilenbook

Откройте «Настройки → Обновления». Автопроверка включена изначально, автоматическое скачивание по Wi-Fi включается отдельно. Доступны ручная проверка, описание релиза, прогресс, отмена и установка скачанного APK. Обновление отмечается на обычном экране приложения; модальное окно поверх чтения не появляется.

Проверка выполняется при открытии/возвращении в приложение: успешная проверка действует сутки, после ошибки повтор возможен через 15 минут. Это не круглосуточная фоновая служба. Автоскачивание начинается только в доступной нетарифицируемой сети Wi-Fi; при её потере останавливается. Прерванный файл скачивается заново. Готовый проверенный APK сохраняется между запусками.

Android подтверждает установку системным окном. При первом обновлении разрешите ilenbook устанавливать приложения и вернитесь назад; приложение повторно проверит файл и откроет установщик. Отказ от разрешения или установки оставляет текущую версию и библиотеку.

0.7.4 — первая версия с встроенным обновлением. Её необходимо один раз установить вручную поверх старой версии. Не удаляйте приложение перед обновлением.

## Источник и проверка

Используется публичный endpoint `https://api.github.com/repos/Lonviser/ilenbook/releases/latest`, без токена и данных библиотеки. Принимается только опубликованный стабильный релиз, тег `vX.Y.Z` и файл `ilenbook-X.Y.Z.apk` из `Lonviser/ilenbook`. Размер ограничен 150 МБ, SHA-256 берётся из GitHub asset digest. Перенаправления ограничены HTTPS и точными доменами GitHub/CDN.

До показа установщика проверяются размер и SHA-256 файла, пакет `by.list.reader`, совпадение версии с релизом, строго больший versionCode, совместимость SDK и SHA-256 сертификата как APK, так и установленного приложения. Принята прежняя релизная подпись `8598bb8e626eb31bc75347f26ecc5a641e20a90e1c128f6db4c2d5a8fbf2e601`. Сборки CI с временным ключом для обновления не подходят.

Файлы находятся в `noBackupFilesDir/updates`. Установщику выдаётся временный доступ только к готовому APK через отдельный ContentProvider. URL и контрольная сумма не принимаются от интерфейса как параметры загрузки. Выход из приложения и повторный запуск требуют повторной проверки сохранённого APK. После установки готовый старый APK удаляется при запуске новой версии.

## Требования к следующим релизам

Сохраните пакет и ключ подписи. Увеличьте versionCode и трёхкомпонентный versionName. Опубликуйте стабильный GitHub Release с тегом `vX.Y.Z` и подписанным `ilenbook-X.Y.Z.apk`. GitHub должен завершить загрузку и выставить `digest: sha256:…`. Черновики, prerelease и APK с суффиксом `-debug` не выбираются.

Нативная реализация: `AppUpdates`, `UpdatePolicy`, `UpdateFileProvider`. Интерфейс: `app-updates.js`. Проверки правил включены в `tools/test-parser.ps1`; сценарий интерфейса — `tools/v11-updates-ui.cjs`.

Официальные справочники: [GitHub Releases API](https://docs.github.com/en/rest/releases/releases), [разрешение установки Android](https://developer.android.com/reference/android/content/pm/PackageManager#canRequestPackageInstalls()).
