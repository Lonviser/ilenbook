# ilenbook 0.7.4

- В настройках появился раздел «Обновления»: проверка стабильного релиза на GitHub, описание изменений, скачивание с прогрессом, отмена и установка.
- Автопроверка при открытии приложения включена по умолчанию. После успешной проверки следующая выполняется через сутки; после ошибки повтор возможен при следующем открытии через 15 минут. Проверка не открывает окна поверх книги.
- Можно отдельно включить автоматическое скачивание по Wi-Fi без тарификации. Оно выполняется при работе приложения; при потере подходящего Wi-Fi скачивание останавливается. По умолчанию автоскачивание выключено.
- APK проверяется по опубликованной SHA-256, размеру, пакету, версии, совместимости Android и прежней релизной подписи. Чужие APK, сборки с другой подписью и откат версии отклоняются.
- Установка запускается кнопкой и подтверждается в системном окне Android. При первом запуске установки может потребоваться разрешение «Установка неизвестных приложений» для ilenbook.

**Первую версию с этой функцией нужно установить вручную:** скачайте `ilenbook-0.7.4.apk` и установите поверх текущей версии без удаления приложения. После этого следующие обновления доступны через «Настройки → Обновления». Android 8.0+, пакет и подпись прежние, книги и заметки сохраняются.

Проверки и скачивание работают при открытии/использовании приложения. Установка без подтверждения и постоянная фоновая служба не добавлены. Для получения обновлений нужен доступ к GitHub. Скачанный APK хранится отдельно от библиотеки и не входит в её ZIP-копию.
