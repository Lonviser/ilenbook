# Проверки ilenbook 0.7.3

23 октября 2026, Europe/Minsk. Изменения касаются размеров и отступов нижней панели чтения. Физическая читалка не использовалась.

Панель проверяется в Chrome и Android 15 x86_64 WebView на ширинах 320/360/412/600: высота 48 точек вместо 76, все три строки помещаются внутри кнопки, стрелки имеют область касания 44 × 44, меню не пересекает панель. Сохранены проценты книги/главы, время и счётчик страниц, проверены перелистывание и открытие меню центральной кнопкой.

Скриншоты Android: [чтение без меню](assets/reader-compact.png), [открытое меню чтения](assets/reader.png).

Используются существующие сценарии `v8-reader-progress.cjs`, `v8-reading-time-ui.cjs` и `v6-reader-customization-checks.cjs`: адаптивность панели, расчёт времени, прокрутка и сохранение места при смене оформления. Синтаксис JavaScript проверяется локально. Стандартные 96 Java-проверок, 15 проверок модели времени и сборка APK выполняются в GitHub Actions.

APK: версия 0.7.3, versionCode 10, `by.list.reader`, Android 8.0+. Проверяются `debuggable=false`, прежний сертификат подписи, совпадение всех 28 файлов assets с исходниками по SHA-256 и восемь библиотек Tor/Lyrebird. Обновление устанавливается поверх 0.7.2 с сохранением семи тестовых книг.

Алгоритмы каталогов, статистики и расчёта времени не менялись. Реальные проверки Флибусты описаны в [отчёте 0.7.1](VALIDATION_0.7.1.md), полок — в [отчёте 0.7.2](VALIDATION_0.7.2.md). Новые сетевые замеры в 0.7.3 не выполнялись.
