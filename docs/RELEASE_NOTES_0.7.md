# ilenbook 0.7.0

Поиск по дополнительным библиотекам, новый экран поиска, выбор вида полки и оптимизация интерфейса. Android 8.0+, пакет `by.list.reader`, versionCode 7. Устанавливается поверх прежних APK с сохранением данных и подписи.

## Поиск

- Добавлены русская Викитека и Internet Archive. Вместе со встроенными OPDS-источниками теперь семь каталогов. В русском режиме два интерфейса одной базы Gutenberg не создают повторный одинаковый поиск.
- Викитека: поиск по заголовкам или текстам, просмотр фрагмента и сохранение текста выбранной страницы в TXT. Извлекаются название и автор, удаляются навигационные блоки, сохраняется ссылка на ревизию. Это отдельная страница, а не автоматическое объединение всех частей произведения. Сервис экспорта EPUB в проверке вернул 503, поэтому этот формат для Викитеки не заявлен.
- Internet Archive: поиск текстовых изданий с объявленными свободными лицензиями, обложки, проверка доступности, выбор оригинального EPUB/TXT. Закрытые, приватные, неподдерживаемые и слишком большие файлы не предлагаются. У сканов качество OCR зависит от издания.
- Новый экран с карточками библиотек, выбором участвующих источников и историей восьми запросов. Историю можно очистить.
- Фильтры источника, EPUB/FB2/TXT, книг/разделов авторов. По умолчанию показываются книги и тексты; разделы можно включить. Сортировка по порядку получения, соответствию или названию.
- Неудачный источник можно повторить отдельно. Двойное нажатие на поиск не запускает копию текущего одинакового запроса. Частичная выдача, отмена, кэш и ранний показ Флибусты сохранены.
- Первоначально отображаются 60 карточек, остальные доступны кнопкой; следующие страницы каталогов запрашиваются отдельно.

## Библиотека и чтение

- Крупная полка, компактная полка или список с сохранением выбора. Обновлены отступы, карточка продолжения с мини-обложкой, типографика, кнопки и экран каталогов. Режим E Ink остаётся контрастным и без декоративной анимации.
- Если локальный поиск ничего не нашёл, можно продолжить тот же запрос в каталогах.
- Поиск по тексту использует индекс открытой книги повторно, не разбирает все главы заново на каждый символ. Подготовка идёт по главам, старые результаты после нового запроса или закрытия окна игнорируются. Структура блоков совпадает с вёрсткой, включая добавленные заголовки.

## Оптимизация

- Сопоставление карточек и очередности использует Map/Set вместо повторного линейного поиска для каждого элемента. Свежая карточка заменяет данные сохранённой карточки, сохраняя её DOM-узел.
- Метаданные нормализуются один раз на объект; заметки не копируются при каждом чтении метаданных.
- Набор в локальном поиске не записывает файл настроек на каждый символ. Необязательное состояние интерфейса сохраняется после короткой паузы, перед уходом в фон и при важных сохранениях.
- Обложки наблюдаются только в добавленных частях интерфейса; кэши запросов ограничены 32 записями каждый. Ошибки не остаются в кэше навсегда.
- Каталоги и их кэш выполняются отдельно от локальных операций и изображений.

Синтетический Node.js-тест объединения 6000 записей: 0.6.0 — 198/192 мс, 0.7.0 — 15/18 мс для первого/повторного прохода на тестовом компьютере. Это сравнение обработки данных, не скорости сети или физической читалки.

## Публикация

Подготовлены публичный репозиторий, README со скриншотами, руководство, описание ограничений, формы issues, рекомендации для изменений и GitHub Actions для проверок и сборки. CI использует временный ключ; APK из Releases подписан прежним ключом владельца.

Яндекс Книги остаётся экспериментальным получением данных аккаунта. Двусторонняя запись точной позиции и заметок не реализована; вход настоящего аккаунта пользователя не проверен. PDF, TTS, постоянные выделения и новый облачный обмен в выпуск не добавлены.
