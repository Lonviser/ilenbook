# ilenbook 0.4.0 — 22 октября 2026

APK для личной установки. Android 8.0+, пакет `by.list.reader`, versionCode 4, прежняя локальная подпись. Устанавливать поверх 0.3.0 без удаления приложения.

## Новое

- Локальная статистика: время по дням/книгам, завершения, активные дни, перелистывания, периоды 1/7/30 дней, CSV, отключение и отдельный сброс. Часы в шапке и пункт настроек. Прошлые часы не восстанавливаются.
- Мобильная навигация, прямое открытие книги, отдельные действия, полка/список, серии и коллекции.
- Страничная вёрстка, касания краёв/центра, жесты, схемы касаний, кнопки громкости по выбору, E Ink. Сохранение фрагмента при смене шрифта.
- Свои TTF/OTF, сноски и базовое оформление EPUB/FB2. Сложная вёрстка поддерживается частично.
- Цитаты, заметки с тегами, черновик, поиск и Markdown. JSON-словарь, явные онлайн-толкования, кэш и личные слова.
- Параллельный поиск без перестановки уже показанных результатов, фильтры, независимые ошибки. Обложки из источника/книги; подбор другого издания по запросу.
- Очередь загрузок, отмена/повтор, дубликаты исходников, передача оригинала другим читалкам.
- ZIP-копирование и восстановление библиотеки с заметками/статистикой/настройками. Приём по Wi-Fi и Android «Поделиться».
- Ссылки Яндекс Книг на полке и входящие ссылки. Подписка используется в официальном приложении/браузере. Автоматической синхронизации с Яндексом нет.

После обновления создайте ZIP-копию в настройках. Для электронной книги оставьте E Ink включённым, выберите размер шрифта, проверьте касания и выделение. Старые книги без оригинала экспортируются в TXT до повторного импорта EPUB/FB2.

Проверено в эмуляторе Android 15 и браузере; аппаратный экран и прошивка физической электронной книги ещё не проверялись. Это локально подписанный APK, публикация в магазинах не выполнялась. Детали — `VALIDATION_0.4.md`.
