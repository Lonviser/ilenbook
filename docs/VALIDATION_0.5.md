# Проверки ilenbook 0.5.0

22.10.2026. Windows, SDK 35 / Build Tools 35.0.0, Android 15 x86_64 эмулятор, Playwright. Никакие настоящие пароли или токены пользователя не использовались.

- `tools/test-parser.ps1`: 18 проверок парсера, 11 архива, 27 протокола Яндекса прошли. Добавлены проверки OAuth state/доменов/повторных параметров, допуска API, модели данных, дубликатов, отсутствующего прогресса и исключения данных аккаунта из ZIP.
- `tools/test-yandex-device.ps1`: 12 нативных проверок прошли. Отдельный тестовый APK использует транспорт с подготовленными ответами и собственную временную папку; в APK приложения тестовые записи не включаются. Проверены Android Keystore AES-GCM, отсутствие открытого токена в файле и снимке, библиотека в две страницы, цитаты/полки/GraphQL, частичный отказ, смена аккаунта, отмена без изменения кэша и удаление данных при отключении.
- `tools/v5-yandex-ui.cjs`: повторное обновление без дублей, совпадение с ручной ссылкой, фильтр статуса и процент, исключение кэша аккаунта из preferences, очистка HTML цитат, поиск/Markdown, раздельная статистика, диагностика без профиля и книг, игнорирование запоздалого ответа, сохранение ручной ссылки при отключении. Пройдено.
- Регрессии `v4-ui-checks`, `v4-statistics-checks`, `v4-queue-checks`: чтение, адаптивность, якорь, заметки, ручные ссылки, локальная статистика и повтор загрузки пройдены.
- `tools/v5-auth-check.cjs`: настоящая страница входа открылась на `passport.yandex.ru`, имеются поля формы, `window.Native` отсутствует. Проверена отмена без подключения и без потери библиотеки из 7 книг.
- Реальный анонимный API: профиль HTTP 401; публичная книга HTTP 200 с названием, автором и HTTPS-обложкой. Полные личные ответы не проверялись.

Тестовый runner устанавливается отдельным APK и не входит в релиз. Запускать нативные тесты на тестовом эмуляторе, не на устройстве с важными сеансами входа: сценарий отключения очищает WebView cookies приложения.

Ограничения: настоящий аккаунт не подключался; точность поля прогресса и доступность разделов для конкретной подписки требуют проверки. Единицы todayTime не подтверждены, поэтому в часы не преобразуются. Обратный обмен точным местом и заметками не реализован. Физическое устройство не проверено. Публикации в магазинах не было.

Результаты финальной установки/подписи — `dist/ilenbook-0.5.0-build-verification.txt`, суммы — `dist/ilenbook-0.5.0-SHA256.txt`.
