# Участие в разработке

Перед изменениями посмотрите [план улучшений](docs/IMPROVEMENTS_0.7.md), [руководство](docs/USER_GUIDE.md) и ограничения движка. Для небольшого исправления откройте pull request; крупное изменение форматов или хранения данных сначала опишите в issue.

## Локальная проверка

Нужны Windows PowerShell, JDK 17+, Node.js и Android SDK Platform 35 / Build Tools 35.0.0.

```powershell
./tools/test-parser.ps1 -JdkPath $env:JAVA_HOME
./build-apk.ps1 -SdkPath $env:ANDROID_HOME -JdkPath $env:JAVA_HOME
node tools/preview.cjs
```

Предпросмотр: `http://127.0.0.1:4189/`. Импорт файлов, сетевые каталоги, экспорт и аккаунт требуют APK. Сценарии Playwright лежат в `tools/v7-*.cjs`; инструкция запуска — в [руководстве](docs/USER_GUIDE.md).

## Что сохранять при изменениях

- Совместимость `by.list.reader`, структуры данных и ZIP-копий.
- Устойчивую привязку позиции и заметок к тексту.
- Работающую офлайн-библиотеку при отказе каталогов.
- Контраст E Ink, доступность управления и ширину 320 px.
- Разделение локальных данных и экспериментального кэша Яндекса.

CI собирает APK временным ключом. Такой файл не обновляет официальный APK из Releases; релизную подпись не нужно передавать в pull request или репозиторий.

Не добавляйте ключи, токены, данные аккаунтов, ZIP личной библиотеки и чужие книги с неясными правами. Собственная лицензия для исходников проекта ещё не выбрана; лицензии сторонних шрифтов и источники встроенных текстов указаны отдельно в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
